# M2-01 — PKI issuance: CSR parsing, client-cert signing, revocation, PKCS#12, client-cert verifier

**Goal:** complete `rustak-server/src/pki/` per `design/03-identity-pki-acme-auth.md` §3 (`csr.rs`, `issue.rs`, `revoke.rs`, `p12.rs`, `tls/{mod,resolver,client_verifier,peer}.rs`) on top of the landed `pki/{keys,ca,pem,server_cert}.rs` and `web/tls.rs` (M0-10/M0-11), persisting issued certs through `db/repos/certificates.rs` (M0-07). Facts: `compat/enrollment.md` (CSR encodings PEM/bare-base64/DER, CN must equal the authenticated username case-insensitively, ATAK sends RSA and `version` param, issued cert = our subject `CN=<user>` + configured O/OU, EKU clientAuth (+ optional TAK channels-marker OID when `[pki].channels_marker_eku`), KU per key type, 128-bit serial, SKI/AKI, validity from `[pki]`, response bodies are bare base64 wrapped at 64 columns).

**Deliver:** `parse_csr` + `CsrPolicy::validate` (signature verified via x509-parser; min RSA bits / ECDSA allowed from config); `issue_client_cert(ca, csr, name_entries, IssueRequest)` via rcgen `CertificateSigningRequestParams` with the subject/SANs/extensions **replaced** by ours; `IssuedCert` persisted (fingerprint, serial, DER, user, device uid, credential id, issued_via, not_before/after) and `RevocationCache` (+ `require_known_cert`) consulted by a rustls `ClientCertVerifier` wrapping `WebPkiClientVerifier` (mandatory vs optional); `PeerCertificate` extraction for actix (`on_connect`) and tokio-rustls; `ResolvesServerCert` hot-swap resolver (used later by ACME); `p12.rs` (client keystore + truststore + legacy signClient v1 bundle, legacy PBES1 3DES/SHA-1 by default via `p12-keystore`, password `[pki].p12_password`); `Pki` facade wiring `load_or_create_root_ca`, server cert, issuance, revocation and `marti_server_config`/`stream_server_config` builders (client cert required) alongside the existing public config. `revoke()` marks the row, updates the cache, and exposes a hook (`on_revoked: Vec<Box<dyn Fn(&Fingerprint)>>` or a channel) that the stream module will use to disconnect sessions (no stream module yet — just the hook + test).
