2. `pages/me.rs` (or extend the existing account view): the signed-in user's own devices and credentials with the same minting flow, so a non-admin can enrol their own phone.
3. `pages/groups.rs` ("Channels"): list/create/rename/delete groups (`/api/v1/groups`), members table with IN/OUT/active toggles (`/api/v1/groups/{id}/members` or the per-user endpoints, whichever M2-02 shipped — check `web/api/{groups,users_groups}.rs`).
4. `pages/devices.rs`: all devices (filter by user/callsign), certificate state, revoke with confirm; wire into the navigation strip.
