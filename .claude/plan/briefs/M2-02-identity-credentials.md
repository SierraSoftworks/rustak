# M2-02 — Identity services: credentials, devices, group membership + admin API

**Goal:** implement `rustak-server/src/identity/{credentials,devices,members}.rs` per `design/03-identity-pki-acme-auth.md` §4 (with plan deltas: kinds `EnrollmentToken` (one-time, `[auth].enrollment_token_ttl`, `max_uses` 1, consumed only on successful signClient), `ClientPassword` (opt-in, `[auth].client_password_ttl`, only when `[auth].client_passwords_enabled`), `ServiceToken`; no local passwords), reusing `rustak_core::identity::password` (argon2id, blocking wrappers), `auth::ratelimit`, and the M0-07 repos (`credentials`, `devices`, `members` incl. `device_group_state`). Provide `Credentials::{mint, verify(username, secret, Purpose), record_use, revoke}` with the constant-time dummy-verify for unknown users and a 5-minute `VerifiedSecretCache`; `Devices::{upsert_seen(uid, user, takv, ip), list, get, delete}`; `Members::{grants_for_user, replace_manual, effective_for_device(user, device) -> GroupSet, set_active(device, groups)}` honouring `[auth].anon_group_default` (`__ANON__` IN+OUT). Then the admin/self-service API per design 03 §6 table: `GET/POST /api/v1/credentials`, `DELETE /api/v1/credentials/{id}` (self or admin; revoke cascades to certs issued with it — call a `pki` hook if present, else leave a clearly named TODO that M2-01/M2-03 wires), `GET /api/v1/credentials/{id}/enroll-url` returning the `tak://com.atakmap.app/enroll?host=&username=&token=` template pieces (the secret itself is only returned at mint time — the UI composes the QR from the mint response), `GET /api/v1/devices`, `GET/DELETE /api/v1/devices/{uid}`, `PUT /api/v1/devices/{uid}/active-groups`, `GET/POST /api/v1/groups`, `PATCH/DELETE /api/v1/groups/{name}`, `GET/PUT /api/v1/users/{username}/groups`. Use the `rustak_api` DTOs from M0-03 (`credential.rs`, `device.rs`, `group.rs`); add DTOs there only if missing (wasm-safe, tests). Audit every mutation.

**Constraints:** only edit `rustak-server/src/identity/**`, `rustak-server/src/web/api/{credentials,devices,groups,users_groups}.rs` + the route registration lines in `web/api/mod.rs`, `rustak-api/src/{credential,device,group}.rs` if needed, and your status file. Another agent edits `pki/**` and another edits `main.rs`/`lib.rs`/`runtime.rs` — do not touch those. No `git`/`but` writes; files < 300 functional lines; handlers thin, logic in `identity/`. Tests: unit per design 03 §9 (`credentials.rs`, `provisioning` not in scope), actix handler tests per endpoint (admin vs self vs other-user 403).
