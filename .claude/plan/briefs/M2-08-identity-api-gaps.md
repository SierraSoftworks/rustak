# M2-08 — Identity admin API gaps found by the UI (certificates, user detail, members, active groups)

**Read first:** `.claude/plan/conventions.md`; status `M2-07-admin-ui-identity.md` ("Server endpoint gaps", the precise list), `M2-02-identity-credentials.md`, `M2-01-pki-issuance.md` (`pki::revoke`, `certificates` repo, revocation cache + live-session disconnect), `M2-06-marti-groups-contacts.md` (members/active-group state and the `t-x-g-c` notifier), and `rustak-server/src/web/api/{users,devices,credentials,groups,users_groups}.rs`, `rustak-api/src/{certificate,device,user,group,credential}.rs`.

**Deliver (all under `/api/v1`, bearer auth, admin unless noted, audited, JSON exactly as the existing handlers emit it):**
1. **Certificates:** `GET /certificates?username&device_uid&state=active|revoked|expired` (admin; a non-admin gets their own), `GET /certificates/{id}`, `POST /certificates/{id}/revoke {reason}` → revokes via `pki::revoke`, updates the revocation cache, disconnects live stream sessions holding that fingerprint (through `LiveState`/`Notifier` if M2-06 exposes it; otherwise the existing revocation hook), 409 when already revoked. `Certificate` DTO gains `fingerprint_sha256`, `not_after`, `revoked_at`, `revocation_reason`, `device_uid`, `username` if missing.
2. `GET /users/{username}` (admin or self) returning the same `User` as the listing; `UserPatch` gains `email: Option<Option<String>>`-style tri-state (serde `double_option`) so the UI can set and clear it.
3. `GET /groups/{name}/members` → `[GroupMember {username, direction, active, source}]`; `GET /devices/{uid}/active-groups` (admin or the device's owner) mirroring the existing `PUT`.
4. `GET /credentials?username=` for admins lists that user's credentials; `GET /credentials?all=true` (admin) lists the installation's, paged (`page`, `limit` ≤ 200), never returning secrets or hashes.
5. Tests for every route (authz matrix: anonymous 401, non-admin 403 where required, self-access where allowed), plus the revoke → handshake-failure path in an existing PKI/stream integration suite if cheap. Update `rustak-ui` API client stubs only if a response shape changed (the UI agent will follow up; do not build UI here).
