1. **Packages:** `GET /packages?missionPackage&q&page&limit` (Resource + `install_on_enrollment`), `POST /packages` (multipart `file`, `name`, `keywords[]`, `groups[]`, `tool`; streamed through `files::upload`), `GET /packages/{hash}`, `PATCH /packages/{hash}` (`groups`, `tool`, `keywords`, `install_on_enrollment`, `expiration`, `name`), `DELETE /packages/{hash}`, `GET /packages/{hash}/content` (streamed). 2. **Clients:** `GET /clients` (`ConnectedClient {client_uid, callsign, username, team, role, takv, protocol, ip, connected_at, last_event_at, incognito, in_groups, out_groups}` from `LiveState`), `DELETE /clients/{uid}` (disconnect), `POST /clients/{uid}/incognito {on}`, `GET /clients/history?secago` (clientEndPoints-style incl. disconnected, from `devices`/`cot_latest`).
3. **CoT:** `GET /cot?type&callsign&group&page&limit` (latest per uid summaries; group-filtered for non-admins by the sender's channel bits `cot_latest` stores), `GET /cot/{uid}` (latest XML + parsed summary), `GET /cot/{uid}/history?secago&start&end&limit` (from the append-only segments, newest first), `DELETE /cot/{uid}` (admin; latest + history).
4. **Settings:** `GET/PUT /settings/files {upload_size_limit_mb}` and `GET /settings/marti {public_host, allow_all_origins}` if `settings.rs` does not already expose them (TOML wins over the settings table, as elsewhere).
5. Tests per route (authz matrix, paging bounds, streaming upload not buffered, history ordering).
