**Deliver, each with a negative test:**
- **H1** enforce the `scope` claim: `Resolved`/`Principal` carry scopes; admin routes require `admin` in scope **and** the account being admin; client-password tokens get the narrow scope the conventions describe; the `/oauth/token` ceiling comment becomes true.
