# M1-05 — `rustak-server::stream` + `cot_store`: TLS listener, hub, router, negotiation, replay

**Goal:** implement `rustak-server/src/stream/**` and `rustak-server/src/cot_store/**` per `design/02-protocol-streaming.md` §2 (files: `mod.rs`, `listener_tls.rs`, `connection.rs`, `writer.rs`, `negotiation.rs`, `subscription.rs`, `groups.rs` (or reuse `rustak_core::identity::GroupSet`), `hub.rs`, `router.rs`, `dest.rs`, `control.rs`, `replay.rs`, `notify.rs`, `mission_hook.rs` (`MissionIngest` trait + `NoMissions`), `metrics.rs`; `cot_store/{mod,writer,latest,history,retention}.rs` using `store::AppendLog` for history and the `cot_latest` table for latest) with the plan deltas: **no TCP listener, no `<auth>`, no anonymous** — the only listener is TLS with client cert required, using `pki::tls::stream_server_config` + `RustakClientVerifier` + `PeerCertificate` from M2-01 and a `CertPrincipalResolver` that maps the peer cert to a `Principal` (CN → user, fingerprint → device row; groups = `identity::Members::effective_for_device`). Behaviour per `compat/streaming.md`: connect → resolve principal → register → replay latest reachable SA (XML) → one `t-x-takp-v` → negotiation; control messages consumed (pong only to pinger; unknown control = no-op); drop messages without `<point>`; flow tags; `<marti><dest>` routing with first-attribute-wins, `All Streaming`, group membership check, mission dest via `MissionIngest` (stub now); reachability sender-IN ∩ receiver-OUT; no echo on implicit broadcast; incognito; disconnect `t-x-d-d`; oversize protobuf → `b-f-t-r` pointer; bounded per-connection writer queues with drop-then-close; `Notifier` trait for missions/groups; `Hub::snapshot()` for `/clientEndPoints`/contacts; `pki` revocation hook → disconnect by fingerprint. Config: use the existing `[stream.tls]` section (add `limits` fields via `config/stream.rs` if missing). Wire `stream::serve` into `runtime.rs` alongside the web server (M0-12) and add the `cot_history` retention job to `jobs/`.

**Read first:** conventions; `compat/streaming.md`; design 02 §2 (all), §4, §5 steps 9–15; status files M1-01/02/03 (cot API), M2-01 (Pki facade, TLS configs, verifier, revocation hook), M2-02 (`Members::effective_for_device`, `Devices::upsert_seen`), M0-09 (AppContext), M0-10 (AppendLog API), M0-12 (runtime wiring), M1-06 (`rustak-client` `Eud` test helper).
