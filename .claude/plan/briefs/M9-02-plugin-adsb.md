# M9-02 — `rustak-plugin-adsb`: aircraft on the map from open ADS-B sources

**Why.** The maintainer wants aircraft from ADS-B on the map, from free/open sources. M9-00 built the shared half (`rustak_client::feed`: `Track`, `TrackKind::Aircraft`, `Area`, `FeedPublisher`, the `Replay` source, the in-process harness); this brief adds the real sources and the ADS-B-specific mapping.

**Read first:** `.claude/plan/conventions.md`; status **M9-00** (the `feed` public API you code against — do not redesign it; additive changes to `rustak-client/src/feed/**` only if a source cannot be expressed, recorded in your status); `rustak-plugin-adsb/**` as M9-00 left it; `docs/plugins.md` "Feed sidecars"; `rustak-server/tests/feed_sidecars.rs`.

**Sources (facts verified by the orchestrator on 2026-09-20 by reading the docs and probing each public endpoint once; re-check before relying on a detail not listed):**
1. **readsb / dump1090 `aircraft.json`** — from a local receiver: a file path (`/run/readsb/aircraft.json`) or an HTTP URL (`http://receiver/data/aircraft.json`, tar1090's `…/data/aircraft.json`). Shape `{"now": <unix s>, "messages": n, "aircraft": [ {…} ]}`. Per aircraft: `hex` (6 hex digits; a leading `~` marks a non-ICAO address), `type` (adsb_icao, mlat, tisb_icao, mode_s…), `flight` (callsign, padded), `r` (registration), `t` (type code), `desc`, `alt_baro` (feet **or the string `"ground"`**), `alt_geom` (feet, WGS-84 ellipsoid — this is the HAE), `gs` (knots), `track` (deg), `baro_rate`/`geom_rate` (ft/min), `squawk`, `emergency`, `category` (`A0`–`D7`), `lat`/`lon`, `nic`, `rc` (m), `seen_pos` (s since last position), `seen`, `rssi`, `dbFlags` (bit 1 = military). Poll every 1–5 s; no terms.
2. **Public aggregators, same shape**: `https://api.adsb.lol/v2/point/{lat}/{lon}/{radius_nm}` → `{"ac": [ … ], "now", "total", "ctime", "ptime", "msg"}` (verified: 109 aircraft in a 25 nm circle, readsb fields); `https://opendata.adsb.fi/api/v2/lat/{lat}/lon/{lon}/dist/{nm}` → `{"aircraft": [ … ], "now", "resultCount", "ptime"}` (verified — note the **different array key**; a `v3/lat/…/lon/…/dist/…` form is documented as preferred); `https://api.airplanes.live/v2/point/{lat}/{lon}/{radius}` (documented as the same shape, 1 request/s; the orchestrator's probe got `403` with a research user agent — treat as unverified, implement behind the same code path, mark it experimental in the README). Radius max 250 nm. Rate limits: adsb.lol "dynamic, API keys planned"; adsb.fi 1 request/s, non-commercial, cite and link; airplanes.live 1 request/s. Send a descriptive `User-Agent: rustak-plugin-adsb/<version> (+https://github.com/SierraSoftworks/rustak)`, honour `429` with `Retry-After`, never poll faster than every 5 s by default, and stop polling on repeated `403` with a clear log line.
3. **OpenSky Network** — `GET https://opensky-network.org/api/states/all?lamin&lomin&lamax&lomax[&extended=1]` → `{"time": <unix s>, "states": [[icao24, callsign, origin_country, time_position, last_contact, longitude, latitude, baro_altitude(m), on_ground, velocity(m/s), true_track(deg), vertical_rate(m/s), sensors, geo_altitude(m), squawk, spi, position_source, category], …]}` (all nullable; `extended=1` adds index 17 `category` 0–20: 2 light, 3 small, 4 large, 5 high-vortex large, 6 heavy, 7 high performance, 8 rotorcraft, 9 glider, 10 lighter-than-air, 11 parachutist, 12 ultralight, 14 UAV, 15 space, 16–17 surface vehicles, 18–20 obstacles). Auth: OAuth2 client credentials at `https://auth.opensky-network.org/auth/realms/opensky-network/protocol/openid-connect/token` (`grant_type=client_credentials`, `client_id`, `client_secret`; token lasts 30 min; refresh on `401`); anonymous works with 10 s resolution and 400 credits/day, authenticated 5 s and 4000/day; a request costs 1 credit for ≤25 square degrees, 2 for ≤100, 3 for ≤400, 4 above; `429` carries `X-Rate-Limit-Retry-After-Seconds`, `X-Rate-Limit-Remaining` shows the balance. Default poll 10 s anonymous / 5 s authenticated, and warn at start-up when the configured area costs more than 1 credit. Terms: research/non-commercial — state it.

**Deliver.**
1. `Source` enum gains `Readsb { url_or_path, poll }`, `Aggregator { provider: adsb_lol | adsb_fi | airplanes_live, poll }` (one implementation, provider picks the URL template and the array key), and `OpenSky { client_id?, client_secret?, poll? }`; `Replay` stays. One file per source under `src/sources/`, each yields `Track`s into the `FeedPublisher`, retries with capped backoff, logs state changes at `info`, never logs credentials (redacting `Debug`).
2. **Mapping** (`src/mapping.rs`, unit-tested): `id = "ADSB-<hex>"` (lower-case, `~` kept); `TrackKind::Aircraft(class)` from the emitter category — `A7` / OpenSky 8 → CivilRotary; `B2` / 10 → LighterThanAir; `B6` / 14 → Uav; `A1`–`A6`, `B1`, `B4` / 2–7, 9, 12 → CivilFixedWing; `C1`–`C3` / 16–17 → `TrackKind::GroundVehicle`; unknown → Unknown; `dbFlags & 1` (military) flips `A*` classes to MilitaryFixedWing; `callsign` = trimmed `flight` else registration else the hex; `altitude_hae_m` from `alt_geom` (feet → m) else `alt_baro` when numeric (feet → m, and say in remarks it is barometric) else `None`; `on_ground` from `alt_baro == "ground"` / OpenSky index 8; speed knots → m/s (OpenSky already m/s); course from `track`; `remarks`: `ICAO`, `Registration`, `Type` (+ `desc`), `Squawk`, `Altitude` (baro ft and geom ft), `Vertical rate`, `Category`, `Emergency` when not `none`, `Source` (adsb/mlat/tisb from `type`), `Seen` (s). Skip aircraft with no position or `seen_pos` > 60 s.
3. **Config** (`config.example.toml`, `deny_unknown_fields`, every key with its default): the M9-00 `Settings` plus the sources; an `[settings.source]` example for each. Defaults: `publish.stale = "90s"`, `min_interval = "5s"`, `max_interval = "60s"`, `min_move_m = 50`.
4. **Tests**: unit tests for every mapping arm, unit conversions, the `"ground"` sentinel, the `~` prefix, the two aggregator array keys; parser tests on **hand-written** JSON samples for readsb, adsb.lol, adsb.fi and OpenSky (including nulls); an OpenSky token-refresh test with `wiremock` (401 → refresh → retry, `429` → wait); an end-to-end test through the M9-00 harness with the `Readsb` source pointed at a `wiremock` URL serving a fixture, asserting the CoT type, callsign, `hae` and `<track>` on a fake EUD; a throttling assertion.
5. **Observability for the Services view (added 2026-09-20).** Report the `FeedCounters` (offered, published, suppressed, expired), the tracked-count, the active source kind and its connection state (connected / reconnecting since / last error, credentials redacted) in the sidecar's heartbeat status through whatever `SidecarContext`/control-link surface M6-01 gives for "saying more than healthy" (see `docs/plugins.md` → Registering with the server → Saying more than "healthy"), so an administrator can monitor the plugin from the admin UI's Services page without reading logs. Mark the service `degraded` when the source has been reconnecting for longer than two poll intervals and `unhealthy` when it has never connected. If the SDK's per-service config KV can be read cheaply at start-up, honour a documented `area` override from it (server-side configuration wins over the file, logged at `info`); if not, say so in the status note rather than building it.
6. **Docs**: `rustak-plugin-adsb/README.md` (what it does, each source with how to obtain access, the data terms and attribution lines the aggregators ask for, the CoT mapping table, credit budgeting for OpenSky, example config, Docker beside rustak); `docs/plugins.md` cross-link; `README.md` — turn "in progress" into a sentence.
