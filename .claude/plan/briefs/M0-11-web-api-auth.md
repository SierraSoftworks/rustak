# M0-11 — admin web server, `/api/v1`, OIDC + passkeys, setup wizard API

**Goal:** `rustak-server/src/web/**` per design 01 §6.1–6.3 with the security deltas: the public listener always serves TLS (`internal` = cert from our CA via M0-10's `pki` + a minimal `ServerCertManager` stub issuing a server cert for `[pki].server_names`; `files` = PEM files; `acme` = **not yet** — return a clear "ACME arrives in M2" error at startup; `none` only with `allow_insecure_http`). Admin API:
- `GET /api/v1/health`, `GET /api/v1/auth/metadata` (`AuthMode::{Oidc, Passkey}`), `POST /api/v1/auth/token` (OIDC code exchange → our JWT; lift `../automate/agent/src/web/helpers/oidc.rs` split into `web/helpers/oidc/{discovery,validate,exchange,claims}.rs`, add PKCE `code_verifier` + nonce support), `POST /api/v1/auth/refresh`, `POST /api/v1/auth/logout`, `GET /api/v1/me`.
- **Passkeys** (`rustak-server/src/auth/passkeys.rs`, `webauthn-rs` current stable, `passkeys` table from M0-07): `POST /api/v1/auth/passkey/register/{start,finish}` (authenticated user, or setup-token during bootstrap), `POST /api/v1/auth/passkey/login/{start,finish}` (→ our JWT). RP id/origin from `[server]` hostname/base URL; challenge state in the kv partition `auth-state` (one-shot, 5 min).
- Setup: `GET /api/v1/setup/status`, `POST /api/v1/setup/admin` (requires the one-time **setup token** generated at first start into `[auth].setup_token_file` and logged; creates the admin user and returns a short-lived registration token so the wizard can register the admin's first passkey), `POST /api/v1/setup/server`, `POST /api/v1/setup/ca` (calls M0-10 `pki::ca`), `POST /api/v1/setup/complete`; all `410` once completed.
- `GET /api/v1/users`, `PATCH /api/v1/users/{username}`, `GET /api/v1/audit`, `GET /api/v1/settings` (admin).
- `api_auth` middleware (bearer = our JWT; `user_acl`/`admin_acl` via filt-rs `AdminRequestFilter` lifted from automate), `Principal` in extensions, `Authenticated`/`Administrative` extractors, `json_error`/`ApiError` (`{"error": …}`), `TracingLogger` + SPA embedding (`web/ui.rs`, `web/telemetry.rs`, `web/helpers/request.rs` lifted), `/robots.txt` before the catch-all. `TestIdentityProvider` lifted into `rustak-server/src/testing/oidc.rs` (feature `testing`) plus code-flow mocks (authorize/token with PKCE check).
